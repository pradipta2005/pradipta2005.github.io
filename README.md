## How to Run the Website

The website is implemented using clean, semantic HTML5, modern CSS3, and lightweight vanilla JavaScript. No framework build step or bundler is required.

### Option 1: Open Directly in Any Modern Web Browser
Simply open `index.html` in your browser:
```bash
# Windows
start index.html
```

### Option 2: Run with a Local Static Server
**Using Python:**
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.

**Using Node.js:**
```bash
npx serve .
```
